# Пропадает интернет при заходе на сервер Rust

Симптом: при подключении к любому серверу Rust пропадает интернет, диагностика
пишет «DHCP-сервер не отвечает», помогает только отключить и снова включить адаптер.

Когда сеть возвращается после перезапуска адаптера, это обычно значит, что зависла
сама сетевая карта, а не роутер. Её «добивает» поток UDP-трафика, который идёт
при заходе на сервер. Чаще всего виноваты:

1. Энергосбережение сетевой карты: Energy Efficient Ethernet / Green Ethernet /
   «Разрешить отключение этого устройства для экономии энергии».
2. Large Send Offload в драйвере Realtek или Intel.
3. «Игровые» программы, которые управляют трафиком: cFosSpeed (он же ASUS GameFirst
   и MSI Gaming LAN Manager), Killer Control Center или Killer Intelligence Center,
   SmartByte (Dell), NetLimiter.
4. Сетевые карты на 2.5 Гбит/с (Intel I225-V/I226-V, Realtek RTL8125) со старым
   драйвером.

## Как запустить

1. Скачай оба файла, `fix-network.ps1` и `run-as-admin.bat`, в одну папку.
2. Запусти `run-as-admin.bat` и подтверди запрос прав администратора.
   Если появится SmartScreen, нажми «Подробнее», затем «Выполнить в любом случае».
3. Скрипт сохранит отчёт `rust-net-report-*.txt` на Рабочий стол и спросит,
   применять ли исправления.

Чтобы только собрать отчёт и ничего не менять, запусти `run-as-admin.bat -ReportOnly`.

## Откат

Скрипт меняет только настройки драйвера: ничего не прошивает и не удаляет.
Перед любым изменением он сохраняет текущие настройки в файл `rust-net-backup-*.json`
на Рабочем столе. Чтобы вернуть всё как было, запусти:

```
run-as-admin.bat -Restore "C:\Users\<ты>\Desktop\rust-net-backup-....json"
```

## Что ещё сделать вручную

- Steam → Настройки → В игре: параметр максимального числа пингов в минуту для
  внутриигрового браузера серверов (в английском Steam он называется
  «In-game server browser: Max pings / minute») поставь 500, а если не поможет, 250. Браузер серверов Rust пингует тысячи серверов
  сразу, и дешёвые роутеры от этого падают.
- Обнови драйвер сетевой карты с сайта производителя материнской платы или ноутбука
  либо с сайта Intel/Realtek. Драйвер из Windows Update для этого не подходит.
- Если интернет пропадает одновременно и на телефоне в той же сети, проблема
  в роутере. Отключи в его настройках DoS Protection / Flood Protection
  (защиту от UDP-флуда) и обнови прошивку.
